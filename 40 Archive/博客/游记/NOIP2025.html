NOIP2025

耳朵同原创2025/11/29大约 5 分钟blog游记

0.前言

感觉CSPS过去才不久就到NOIP了，时间确实是非常快的。
在初中的时候复赛分数不够高，所以这次就是第一次NOIP咯。

1. 在考试前

CSP之后就是运动会，然后又是段考。所以这一个月都没怎么做题，也就学了一些基础算法，比如dij。之前我甚至只会写SPFA
考前晚上，复习一下线段树树剖啥的就上床睡觉了。虽然似乎都没考到

2.路途中

沟槽的CCF怎么又选深高级高中园做考场
NOIP的位置又一次选在了这里，之前CSP J ／S2024的时候也是在这。
因此，又要坐50公里车过去了。

六点被闹钟摇起来，清晨的寒意还在，检查一下收拾好的东西，钻到车里继续睡觉。

从无意识状态再次醒来，出乎意料，42分钟就到了。周围又成了深圳郊区的模样—深高级高中园已经近在咫尺了。出乎意料的是，这次完全没堵车。
阳光从斜侧洒满了大地，空中万里无云，虽然还是有点冷，不过也算得上好天气了。
穿过一个桥洞，便又看到了CCF的牌子，还是立在那个地方。

时间略早，要先在报告厅等几分钟。同样与同学寒暄几句，就跟着队伍上楼去机房了。
不过这次上去着实是早，相比CSP只剩二十分钟才放我们进去，这次07:55就放我们进去了。

和深外高中园一样，深高级高中园也是在顶楼。中间，四面墙围成了一个天井。若只往中间看，除了教学楼，只能看到湛蓝的天空。配上打进来的阳光，似有一种在极高处向上眺望的感觉，给人一种平静感。若周围无人，日程表空白，在此处走走，应该能抚平躁动的思想。

不过沟槽的CCF依然不给带吃的，只能先吃个巧克力饼干再进考场了

3.考试间

没做点前些年的NOIP题体现的淋漓尽致，做不出来一点。

T1 candy

按照常理，应该要不是思想题要么是贪心。
但是这一看。。怎么这么像完全背包问题。
好在题意还算好理解，搓个暴力就走了。
后面其他题实在写不出来了，所以回来再写一下，把特殊性质A写了个完全背包。又混了10分。

正解听同学说应该是贪心，但是对着excel想了半天也没想出来策略，赛后看看吧

T2 sale

这题就完全看不懂了。
让我求方案数，但是方案检测也是有点难的。猜了个结论，没对。
这题估计一分没有，而且这么大的数据量应该就是dp了。
不过CCF居然把测试点编号也加到输入里面了，估计是方便判断特殊性质吧
应该和CSPS T2一样各种做法一大堆

T3 tree

一看题面，似乎很简单，让我统计一下树的最小非负未出现整数的权值和。
但一做起来就发现不简单了，每个子树要选的数都要考虑其他的子树，同时统计这个集合、算总和也麻烦，时间复杂度直接上天。
最后放弃这道题了，搞了个基于树剖运算的，能过部分样例的任务，希望能混几分

T4 query

区间查询问题，而且算比较麻烦那种类型的，写个暴力，能过一些数据。
但是这个题的输出上也要玩花活，位运算，取模都整上了。还是mod 2642^{64}264，只能用unsigned long long溢出了。但是位运算不知道为什么算出来是错的，最后应该还是没分

4.考场之后

相比CSP，这次是一题都没做出来，对自信有些打击。

机房一进一出，四个半小时就过去了。户外原本在阴影里的包也罩上了阳光。经过太阳辐射一上午的努力，24°C，十分适宜的温度。

回程选择坐地铁，但可惜没自行车，只能走去坐地铁。

这边似乎是以低碳为主要的建设方向。一点半，约莫也算是下午了，路边公园草地上已经多了许多露营毯，许多游人或居民来这享受着阳光。别说，这公园建的确实十分漂亮，草地、山、树、天桥、游人、低碳馆.....各种景物松散的交织在一起，缺了些莲花山公园的整齐有序，多了些慵懒的氛围。

这边的地铁站的椅子倒是也有几分别致，是在一片弧形的材料上的，也许是为了环保。但别说，坐起来确实比不锈钢的椅子舒服了许多

5. 后记

分数: 35 / 0 / 0 / 0

打完NOIP，接下来该集中在下周的段考上了。
这次确实是到能力边界了，应该和我初三松懈了一年有关。
好在高中每周都能练OI了，希望蒟蒻我到明年NOIP能切出来至少一道题吧。

本文在回家的地铁上写完
